# Reusable production brief

This is an optional intake template. [SYSTEM_PROMPT.md](SYSTEM_PROMPT.md) is the single master.

```text
Topic or Bible passage:
Main question or lesson:
Requested length:
Aspect ratio:
Any wording to preserve:
Any real personal experience approved for this video:
Any changes to the approved presenter, voice, or visual style:

Produce and deliver for review. Do not publish.
```

Reuse established answers and approved assets. Do not ask the user to fill every field when the information is already known.

For an explicit pilot, target 45–55 seconds and remain strictly below 60 seconds. For a full film, use the requested length and divide high-quality presenter generations into supported segments. Never silently substitute a pilot for a full production.

See [PETER_PILOT.md](PETER_PILOT.md) for a generic story example. Keep actual run status, private assets, credentials, and production identifiers outside this public repository.
